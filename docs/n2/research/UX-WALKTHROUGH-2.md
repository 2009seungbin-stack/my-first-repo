## 1. 모더레이터 흐름 (신고 → 임시조치 → "임시조치 중" → 복구)

**확인됨**
- 신고 화면(`/ko/community/report?target=discussion:demo-18`)에 대상 글 제목이 나오고, 사유 기본값은 "사유를 선택하세요"(필수)입니다. 제출하면 "신고를 접수했어요. 운영자가 확인합니다." 토스트가 뜨고 원래 글로 돌아갑니다.
- 열린 신고를 다시 하면 "이미 신고한 대상이에요. 사유를 “스팸·도배”에서 바꿨어요."라고 알려 줍니다.
- `/ko/community/mod` 큐에 한국어 사유, 작성자, 본문 미리보기, **신고자 설명**이 모두 보입니다. 임시조치를 누르면 사유를 묻고, 항목은 "임시조치 중" 목록으로 옮겨 갑니다(새로고침해도 남아 있음). 여기서 "복구"를 누르면 글이 200으로 돌아옵니다. 버튼도 상태에 맞게 나옵니다(숨긴 항목에만 "복구").
- 숨긴 글은 첫 화면, 채널 목록, 념글, 검색 어디에도 나오지 않습니다(`/ko/ai/claude/7`으로 확인).
- 숨긴 글이나 삭제된 글의 주소로 가면 "삭제되었거나 숨겨진 글입니다 · ○○ 채널로 가기 ›" 페이지가 나옵니다(비로그인·로그인·모더레이터 모두 같음).

- 1차의 blocker는 **해소됐습니다.**

1. **(major) 레이더 "내 구독만"이 구독한 작품의 굿즈 마감을 숨김.** 「약사의 혼잣말」을 구독했는데 D-1 마감 굿즈가 필터에서 사라지고, 빈 상자에 안내도 없습니다. 굿즈를 작품 ID로 매칭하고, 빈 상태 문구를 넣고, 필터는 서버에서 다시 불러와 30개 상한에 잘리는 일정(블리치 50화 D-28)도 포함합니다.
