PHASER (src/core/Config.js)
- 3.90 line ~401: pixelArt default = (this.zoom !== 1) -> with scale.zoom != 1 pixelArt turns ON by itself. Docs (3.88.2 typedef) say default false. 4.2 line ~397: default false (no zoom rule). -> verify in browser.
- Both: pixelArt -> antialias=false, antialiasGL=false, roundPixels=true.
- 4.x only: smoothPixelArt (WebGL) -> antialias true, pixelArt false; shader keeps blocky texels with smooth edges.
- antialias=false effects (core/CreateRenderer.js): CanvasPool.disableSmoothing(); CanvasInterpolation.setCrisp(game.canvas) sets style image-rendering through a list ending in 'pixelated' + msInterpolationMode; TextureSource ctor: setFilter(1)=NEAREST for every texture (textures/TextureSource.js ~269/281). 4.x WebGLTextureWrapper minFilter NEAREST (~328).
- antialiasGL -> WebGL context antialias (MSAA), does not affect textures.
- Phaser has no devicePixelRatio handling (only OS.pixelRatio read). Canvas buffer = game size; CSS size = displaySize (zoom / FIT).
- Scale: scale.snap {width,height} -> displaySize.setSnap (floors to multiples); zoom; Phaser.Scale.MAX_ZOOM (-1) = largest integer zoom fitting parent (getMaxZoom, SnapFloor, min 1); autoRound floors style size. Modes NONE, WIDTH_CONTROLS_HEIGHT, HEIGHT_CONTROLS_WIDTH, FIT, ENVELOP, RESIZE, EXPAND (both versions).
- Camera: CameraManager.roundPixels = game.config.roundPixels; camera.startFollow(target, roundPixels=false, ...) OVERWRITES camera.roundPixels (default false) in 3.90 and 4.2 -> pass true.
- 3.90: Camera.renderRoundPixels = roundPixels && integer zoom; MultiPipeline floors gameObject x/y when camera.roundPixels; camera scroll floored when roundPixels.
- 4.2: GameObject.vertexRoundMode default 'safeAuto' = round only when the final matrix is translate-only (no scale/rotation incl. camera zoom) AND camera.roundPixels. 'fullAuto' = always when camera.roundPixels; 'full' always; 'off'; setVertexRoundMode(). So scaled sprites / camera zoom != 1 are NOT rounded by default in 4.x (renderer/webgl/renderNodes/transformer/TransformerImage.js ~180).

PIXI 8.21 (lib/)
- TextureStyle.defaultOptions = {addressMode:'clamp-to-edge', scaleMode:'linear'}; TextureSource ctor spreads TextureSource.defaultOptions into new TextureStyle -> TextureSource.defaultOptions.scaleMode='nearest' works (options pass through).
- source.scaleMode setter -> style.scaleMode (sets mag/min/mipmap filter).
- roundPixels: AbstractRenderer default false; Sprite has own roundPixels; shader roundPixels() rounds positions to render-target pixels (device pixels when resolution=dpr).
- autoDensity default false; with autoDensity canvas style width/height = CSS size, buffer = size*resolution (CanvasSource.resizeCanvas). resolution default expected 1 (verify).
- Bitmap font loader: non-SDF .fnt page textures get default options (global 'nearest' applies); SDF pages forced linear. BitmapFont.install({... textureStyle:{scaleMode:'nearest'}}).

CSS / DOM (MDN, fetched): image-rendering only affects scaled images; 'pixelated' spec = nearest to nearest integer multiple then smooth for remainder (MEASURE what Chromium does at a fractional factor). devicePixelContentBoxSize via ResizeObserver({box:'device-pixel-content-box'}) = exact device pixels; not Baseline.
