## 중요한 환경 한계

브라우저의 `http://127.0.0.1` 탐색은 실행 환경 정책으로 `ERR_BLOCKED_BY_ADMINISTRATOR`가 발생했습니다. 브라우저 검사는 같은 소스를 Blob 모듈로 마운트하고 **모듈 URL, location/history, Storage 경계만** 시험용으로 대체했습니다. 언어 선택 로직과 처리 엔진은 제품 코드 그대로 실행했습니다.

따라서 위 수치는 공개 호스팅의 HTTP 탐색·CSP, 실제 브라우저 Storage의 재방문 지속성, 외부 모델/CDN, 실제 Worker 성공 경로, 실물 저사양 기기 성능까지 성공했다는 의미가 아닙니다. 픽셀/단색 제거는 이 환경에서 제품의 호환 처리 경로로 검사했습니다.

PDF 페이지 합치기·주석·저장, HEIC 디코딩, MP3 인코더, AI 인물 모델은 외부 엔진 다운로드 후 끝까지 처리되는 과정을 이번 환경에서 검증하지 못했습니다. 해당 기능의 유입 화면과 앱 번역은 구현되어 있습니다.

## 다시 실행

Node.js 20 이상에서 `npm test`, `npm run check`, `npm run build`를 실행하세요. 브라우저 검사에는 Python Playwright, Pillow, `/usr/bin/chromium`이 필요합니다. 일반 환경은 `npm run dev` 후 `python tests/browser.py`, 제한 환경은 `python tests/browser.py --in-memory`를 사용합니다.

언어 자동 선택·명시 선택·보존 테스트 중 Storage를 직접 주입하는 일부 경우는 메모리 모드에서만 실행됩니다. 일반 브라우저에서는 직접 ko/en/ja 선택 후 재접속해 지속성과 언어 전환 시 편집 결과 보존을 추가로 확인하세요.

원래 v1의 이전 검사 기록은 이 변경의 새 실행 결과로 취급하지 않았습니다.

추가 회귀 검사: 일본어 GIF 유입 → 실제 WebM 입력 → 8프레임 GIF 저장 → Pillow 재열기까지 통과했습니다. GIF 루프의 시간 변수와 번역 함수 이름 충돌을 수정했습니다.
