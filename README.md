# FileForge Studio · v1.1

**한 파일로 이어서 작업하는 로컬 편집기.** 이미지 편집, PDF 편집, 도트화, 미디어 편집을 네 개의 작업실로 묶었습니다.

## 유입 UX + 다국어

- `/image/upscale/`은 업스케일 안내와 배율 선택부터 시작합니다. 배경제거, 압축, 변환, 자르기, PDF 합치기 등도 각 목적에 맞는 입구를 사용하고 내부 편집 엔진을 공유합니다.
- 파일 선택 → 실행 → 실제 결과 확인 → 다운로드 → 관련 작업으로 이어집니다. 결과 확인 전에 파일을 자동 다운로드하지 않습니다.
- **한국어 / English / 日本語** 및 자동 감지를 지원합니다. 우선순위는 `?lang=` → URL 언어 접두사 → 저장된 선택 → 브라우저 선호 언어 → 영어입니다.
- 언어 변경은 파일을 다시 불러오지 않으며, 편집 결과와 입력 중인 설정을 유지합니다. 기기에는 선택한 언어만 저장합니다.
- 홈에서 업스케일·배경제거·압축·PDF 합치기를 바로 찾을 수 있고, 보조 기능은 아이콘·툴팁으로 유지합니다.

예시: `/en/image/upscale/?scale=4`, `/ja/pdf/merge/`, `/ko/pixel/?n=48`, `/png-to-webp/`.

## 실행과 배포 파일

Node.js 20 이상. 기본 실행에는 `npm install`이 필요하지 않습니다.

```sh
npm run dev
# http://127.0.0.1:4173/
npm run check
npm test
npm run build
# dist/ 전체를 정적 호스팅에 배포
```

빌드는 도구와 About/Privacy/Terms/Contact의 자동 감지용 주소 및 ko/en/ja 주소를 합쳐 **128개 정적 HTML 진입 파일**을 만듭니다. `SITE_URL`을 지정할 때 canonical/hreflang/Open Graph URL과 sitemap 절대주소를 추가합니다. 주소가 없으면 도메인을 만들지 않고 빈 sitemap과 기본 robots를 생성합니다. 기능 수를 뜻하는 숫자가 아닙니다.

**[Cloudflare Pages 배포·커스텀 도메인·Search Console·AdSense 설정 가이드](DEPLOYMENT.md)**

Cloudflare Pages 설정은 `main` / `npm run build` / `dist`입니다. Node는 `.node-version`에 **22.23.2**로 고정하고 Node 20+ 호환 범위도 유지합니다. GitHub 반영은 실제 사이트 배포와 다릅니다.

각 도구 아래에 사용법·지원 형식·특징·한계·FAQ를 세 언어로 제공합니다. 도구를 먼저 사용할 수 있도록 기존 편집기 아래에 배치했습니다. 정책 링크는 새 탭에서 열고, 도구의 언어 변경은 파일·설정·결과를 보존합니다.

광고는 기본 **비활성**입니다. 실제 `ADSENSE_CLIENT`가 있을 때만 광고 스크립트와 ads.txt를 생성합니다. 수동 광고 단위와 CMP 확인이 있어야 콘텐츠 슬롯을 만들며, 광고 활성 빌드에만 요청별 nonce CSP를 위한 Pages Worker를 포함합니다. 세부 활성화 순서와 운영자 체크리스트는 배포 가이드를 따르세요. 가짜 게시자 ID·연락처·도메인은 배포하지 않습니다.

## 기능과 중요한 구분

**이미지:** 자르기·회전·반전·리사이즈, 일반 2×/4× 확대, 단색 배경제거, 선택적 AI 인물 제거, 외곽선·여백, PNG/JPG/WebP, 목표 용량, 일괄 ZIP.

**PDF:** 파일·이미지 추가, 페이지 순서·회전·삭제·복제, 범위 추출, 글자·이미지·펜·도형 추가, PDF 또는 페이지 이미지 출력.

**도트화:** 실제 8–512 N×N PNG, 팔레트 제한, 디더링, 투명 여백·외곽선, 정수배 저장, 16/32/64/128 팩.

**미디어:** 지원 코덱의 짧은 영상·음성, 프레임 PNG, GIF, 실시간 WebM 구간 저장, WAV/MP3 추출.

확대는 **AI 복원이 아닙니다**. AI 배경제거는 인물용 실험 기능이며 일반 물체용 모델이 아닙니다. PDF 기존 본문 직접 수정·OCR·보안 마스킹·인증서 서명은 지원하지 않습니다. 이미지 기반 PDF 축소는 글자 선택·검색을 잃을 수 있어 명시적으로 선택해야 합니다. 영상 출력은 MP4가 아닌 WebM이며 프레임 단위 정밀 컷이 아닙니다.

PDF·HEIC·MP3·AI는 외부 엔진이나 모델을 추가 다운로드합니다. 파일 업로드 API, 분석 추적기, 계정, 서버 편집 저장은 없습니다. 광고를 끈 기본 빌드도 선택 기능에는 외부 요청이 있어 **네트워크 통신이 전혀 없는 서비스는 아닙니다**. 기기별 속도·메모리 사용량·호환성도 보장하지 않습니다.

## 검증 범위

이번 작업의 실행 결과와 재현 명령은 [테스트 기록](docs/TESTING.md)에 구분해 기록합니다. Node 검사 숫자는 번역 항목·라우팅·HTML·빌드 설정 등의 테스트 케이스 수이며 기능 수가 아닙니다. 브라우저 검사는 실제 로컬 HTTP에서 수행합니다. 광고 테스트는 Google 요청을 가로채며 실제 광고 게재·동의 시스템·공개 Cloudflare HTTPS·Search Console 색인·AdSense 승인은 별도 운영 검증이 필요합니다.
