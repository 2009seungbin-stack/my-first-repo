# FileForge v1.1 · 유입 UX와 다국어

## 사용자 흐름

홈은 파일 중심, 기능 링크는 목적 중심입니다. `/image/upscale/`은 업스케일 안내·2×/4× 선택만 먼저 보여주고, 파일을 넣어도 같은 목적을 유지합니다. 내부 엔진은 기존 이미지/PDF/도트/미디어 편집기를 공유합니다.

집중 작업은 **파일 선택 → 실행 → 실제 결과 확인 → 다운로드 → 관련 작업** 순서입니다. 실행 버튼과 다운로드 버튼은 구분합니다. 압축 결과의 실제 바이트 수를 확인하고 목표를 만족하지 못하면 성공으로 표시하지 않습니다. 업스케일 배율을 바꿔 다시 실행해도 이전 결과를 또 확대하지 않고 현재 작업 원본에서 다시 계산합니다. 결과를 다음 이미지 작업으로 보내는 경우에만 편집 원본으로 적용합니다.

홈에는 업스케일·배경제거·압축·PDF 합치기 진입 카드를 표시합니다. 상위 편집기는 여전히 네 개입니다. 이름 없는 아이콘만 강요하지 않고, 핵심 실행 버튼에는 짧은 동작 이름을 표시합니다. 보조 도구는 툴팁, 키보드 포커스, 모바일 길게 누르기와 이름 표시 옵션을 유지합니다.

## 언어

현재 지원: **한국어(ko), 영어(en), 일본어(ja)**.

우선순위는 `?lang=` → URL의 `/ko/`, `/en/`, `/ja/` → 이 기기에 저장한 수동 선택 → `navigator.languages` → 영어입니다. `en-US`, `ja-JP`, `ko-KR` 같은 지역 태그를 기본 언어로 정규화합니다. 지원하지 않는 후보는 다음 선호 언어로 넘어갑니다. 위치·IP 기반 추정이나 번역 API는 사용하지 않습니다.

상단 언어 선택은 파일을 재로드하지 않습니다. 파일, 결과, 되돌리기 기록, 열려 있는 설정의 입력값을 유지합니다. 직접 선택한 언어만 `fileforge.language.v1` 키에 저장합니다. 저장소 접근이 차단되어도 현재 방문에서는 언어가 바뀌고 실패를 안내합니다. 자동 감지를 선택하면 저장한 선택과 URL 언어 지정을 해제합니다. 처리 중에는 언어 변경을 막아 작업 진행 문구가 섞이지 않도록 합니다.

새 메시지는 `src/messages.js`에 `[한국어, 영어, 일본어]`로 추가합니다. 기존 UI는 한국어 원문을 gettext 방식의 메시지 식별자로 사용하며, 새 UX는 의미 기반 키를 사용합니다. `t()`가 명시적으로 호출된 앱 문구만 번역합니다. 파일명·사용자 주석을 DOM 검색으로 바꾸지 않습니다. 외부 라이브러리가 직접 반환하는 진단문은 공급자의 언어로 나올 수 있습니다.

## 유입과 언어 URL 예시

- `/ko/image/upscale/?scale=4`
- `/en/image/remove-bg/`
- `/ja/image/compress/?kb=200`
- `/ja/pdf/merge/`
- `/en/pixel/?n=48`
- `/png-to-webp/`

언어 접두사가 없는 주소에서는 자동 감지와 저장된 선택을 사용합니다. URL 접두사와 쿼리는 공유 상대가 같은 언어/목적으로 들어오도록 할 때 사용합니다. 공유 링크에 파일 데이터는 포함하지 않습니다. 언어를 바꾸면 현재 경로의 언어만 교체하고, 도구 진입이나 뒤로가기는 목적·기본 설정을 함께 복원합니다.

GitHub 저장소 하위 배포 경로에서도 앱 스크립트 위치를 기준으로 URL을 계산합니다. 사이트 배포를 자동으로 설정하지는 않습니다.

## 정적 페이지와 메타데이터

`npm run build`는 언어 없는 28개와 ko/en/ja 각 28개, 총 **112개 HTML 진입 파일**을 생성합니다. 언어별 제목·설명·Open Graph·`html lang`·랜딩 본문이 정적으로 들어갑니다. 검색 노출이나 광고 승인을 보장하는 기능은 아닙니다.

실제 배포 주소가 정해지면 다음처럼 빌드합니다.

```sh
SITE_URL=https://your-real-domain.example/ npm run build
```

위 주소는 사용법을 보여주는 예시이며 실제 서비스 주소가 아닙니다. `SITE_URL`이 지정된 경우에만 실제 기준 주소를 이용해 canonical, hreflang 및 sitemap을 생성합니다. 지정하지 않으면 도메인을 추측해서 넣지 않습니다.

## 유지되는 기능 한계

업스케일은 일반 보간 확대이지 AI 디테일 복원이 아닙니다. 기본 배경제거는 가장자리에 연결된 단색 제거이며, AI 모드는 선택적으로 다운로드하는 인물용 모델입니다. PDF의 이미지 기반 압축은 글자 선택·검색 등을 잃을 수 있어 자동으로 활성화하지 않습니다. PDF의 기존 본문 편집, 보안 마스킹, MP4 재인코딩은 추가되지 않았습니다.

이번 변경의 외부 PDF/HEIC/MP3/AI 엔진은 전체 처리 성공을 재검증하지 못했습니다. 검증 범위는 `TESTING.md`를 확인하세요.
