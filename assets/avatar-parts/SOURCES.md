# Original avatar part previews

These thumbnails are generated from the project's original 16×16 pixel part shapes in `src/avatar/render.js`. The shapes were drawn by the Nerulio project for this tool on 2026-09-28. No art from Picrew, competitors, stock sprite packs, or user uploads is present in these files. The author dedicates the original part artwork and these derived previews to the public domain under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/), to the extent of the author's rights.

`manifest.json` records each named part's 64×64 preview SHA-256, a pinned source URL, source file SHA-256, date, and license. A preview shows the selected part on a standard neutral avatar so its visual effect can be compared; it is not a standalone layer mask. The in-browser avatar composites the source shapes at 16×16 and scales only by integer nearest-neighbor factors. User-provided backgrounds are outside this CC0 dedication.

Rebuild after a committed renderer change with `python tools/generate-avatar-parts.py`. The script refuses an uncommitted renderer or catalog so the pinned source URL points at the exact published version used for the previews.
