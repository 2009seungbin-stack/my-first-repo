# FileForge Studio

**파일 한 번, 편집은 한곳에서.** 정적 웹사이트로 동작하는 아이콘 중심 로컬 편집기입니다.

상위 메뉴는 **이미지 / PDF / 도트화 / 미디어** 네 개입니다. 압축·형식 변환은 이미지 저장 패널에, PDF 합치기·분할은 페이지 작업과 저장 범위에 통합했습니다. 도구별 URL은 별도 앱이 아니라 같은 편집기를 적절한 상태로 엽니다.

## 실행

Node.js 20 이상이 필요합니다. 기본 실행·빌드에 npm 패키지 설치는 필요하지 않습니다.

```sh
npm run dev
# http://127.0.0.1:4173/

npm test
npm run check
npm run build
# dist/ 전체가 정적 배포 결과입니다.
node tools/serve.mjs --dist
```

`file://`로 index.html을 직접 열지 말고 HTTP 또는 HTTPS로 서비스하세요. GitHub에 코드를 올리는 것과 공개 사이트 배포는 별개입니다. 이 저장소에는 자동 배포나 광고 계정이 연결되어 있지 않습니다.

## 포함된 편집기

| 편집기 | 구현 범위 |
| --- | --- |
| 이미지 | 자르기, 회전, 좌우 반전, 비율 유지 크기 변경, 일반 2×/4× 확대, 단색 배경 제거, 실험적 AI 인물 배경제거, 배경색·외곽선·투명 여백, 되돌리기, PNG/JPG/WebP 저장, 목표 용량, 일괄 ZIP |
| PDF | 여러 PDF·이미지 추가, 페이지 순서·회전·삭제·복제, 범위 추출, 텍스트·이미지·펜·도형·하이라이트 추가, PDF 또는 페이지 이미지 저장, 선택적 이미지 기반 PDF 용량 축소 |
| 도트화 | 16/32/64/128 및 사용자 지정 8–512 정사각형 에셋, 팔레트 제한, 디더링, 투명도·여백·외곽선, 정수배 미리보기 저장, 여러 크기 ZIP, 이미지 편집기로 결과 전달 |
| 미디어 | 브라우저가 읽는 영상·오디오, 프레임 PNG, 짧은 GIF, 구간 WebM 저장과 축소, WAV/MP3 오디오 추출 |

### 반드시 구분할 점

- **확대는 브라우저 보간/최근접 확대입니다. AI 복원이나 새 디테일 생성이 아닙니다.**
- AI 배경제거는 선택적으로 불러오는 **MODNet 인물용 실험 기능**입니다. 일반 사물 전용 모델이나 완벽한 자동 누끼를 의미하지 않습니다. 기본 단색 제거는 AI가 아닙니다.
- PDF는 기존 글자를 직접 고치는 워드프로세서가 아닙니다. 새 글자는 이미지 레이어로 얹습니다. 양식·전자서명·접근성 구조 보존을 보장하지 않습니다.
- PDF의 도형/하이라이트는 **보안 마스킹(redaction)이 아닙니다**. 원본 내용 삭제가 필요한 민감한 문서에 사용하지 마세요.
- PDF 이미지 기반 축소는 선택 가능한 글자·벡터를 잃습니다. 반드시 원본을 보관하세요. 더 작은 파일을 보장하지 않습니다.
- 영상 저장은 **WebM**이며 실시간 기록입니다. MP4 출력·프레임 단위 정확한 컷 편집이 아닙니다. GIF는 최대 8초, 구간 저장/오디오 추출은 최대 120초입니다.
- HEIC, PDF, MP3 및 AI 기능은 외부 라이브러리/모델 다운로드가 필요합니다. 기본 이미지·도트·GIF 엔진과 달리 이 경로의 실제 외부 라이브러리 통합 실행은 이번 환경에서 검증하지 못했습니다.

## 파일과 네트워크

선택한 파일은 브라우저에서 처리하며 이 구현에는 파일 업로드 API가 없습니다. 광고·분석 스크립트도 없습니다. 다만 선택 기능을 누르면 jsDelivr/Hugging Face에 프로그램·모델 요청이 발생합니다. **네트워크 통신 없음**이나 **처음부터 완전 오프라인**을 의미하지 않습니다. 제삼자 코드의 실행 권한과 공급망 위험도 고려해야 합니다. 자세한 버전·출처는 [docs/DEPENDENCIES.md](docs/DEPENDENCIES.md)에 있습니다.

이미지 한 장 32MiB, 한 번에 24장, 선택 파일 합계 128MiB, 최대 1,600만 픽셀을 기준으로 제한합니다. 순차 처리·축소 미리보기·제한된 되돌리기 기록을 사용하지만 이는 **실제 메모리 사용량 상한이나 저사양 성능 보장이 아닙니다**. AI와 PDF는 추가 메모리가 필요합니다.

## 직접 진입 URL

`/image/compress/?kb=200`, `/image/convert/?format=webp`, `/image/crop/`, `/image/remove-bg/`, `/image/upscale/`, `/pdf/merge/`, `/pdf/split/`, `/pdf/compress/`, `/jpg-to-pdf/`, `/pdf-to-jpg/`, `/pixel/?n=48`, `/video/to-mp3/` 등입니다.

`npm run build`는 홈과 23개 진입 경로를 만듭니다. 상대 `<base>`로 저장소 하위 경로에서도 정적 파일을 찾습니다. 사용 중 편집기 이동은 파일을 다시 올리지 않습니다. 공유 링크에는 파일이 아닌 일부 도구 설정만 들어갑니다.

## 검증 상태

2026-09-20 기준 순수 로직·라우팅 **56개 검사**, 메모리 마운트 Chromium DOM/Canvas·실제 이미지/GIF/WebM 저장 **38개 검사**가 통과했습니다. 자세한 환경·제외 범위는 [docs/TESTING.md](docs/TESTING.md)를 보세요.

공개 호스팅 HTTP/CSP, 실제 Worker 실행 경로, 외부 PDF/HEIC/MP3/AI 통합, 실물 저사양 기기는 검증하지 못했습니다. 숫자는 이런 부분까지 성공했다는 의미가 아닙니다.

## 구조

- `src/app.js`: 네 편집기 UI, 파일 상태, 작업 전환
- `src/core.js`: 도트 팔레트·디더링, 단색 제거, ZIP/GIF, 입력 검증
- `src/image.js`: Canvas 편집·인코딩, Worker/호환 경로
- `src/pdf.js`: PDF 페이지·주석·내보내기
- `src/media.js`, `src/audio-worker.js`: 미디어 처리
- `src/ui.js`: 아이콘, 툴팁, 접근성 안내
- `tools/`: 의존성 없는 로컬 서버·정적 빌드
- `tests/`: 순수 로직 및 브라우저 검사

기존 저장소 README 내용은 [docs/original-README.md](docs/original-README.md)에 보존했습니다. v0.2의 분산 도구 구조를 참고해 통합 작업실로 재구성했습니다. 아직 자동 배포, 로그인, 결제, 광고, 서버 업로드, AI 고해상도 복원, OCR은 포함하지 않습니다.
