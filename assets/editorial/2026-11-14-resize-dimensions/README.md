# Resize enlargement-limit evidence (2026-11-14)

The 32 x 24 diagnostic pattern is generated by the measurement script. It contains no third-party image. The 24 PNG outputs were downloaded through the actual resize interface: 3 fit modes x 2 target boxes x 2 limit states x 2 browser engines. Pillow independently decoded their formats, dimensions and alpha bounds. Dimensions are not a file-byte or visual-quality guarantee.

Measurements came from the immutable preview https://2b404dbc.nerulio.pages.dev at c8ad20875e9504b29cc7890c98fd7b171afdcbdb, verified before and after each browser run. This dataset is preview evidence, not proof of deployment to nerulio.com. Browser and Pillow versions, exact input/output hashes, byte counts and alpha bounds are in measurements.json.

Resize source: https://github.com/2009seungbin-stack/my-first-repo/blob/c8ad20875e9504b29cc7890c98fd7b171afdcbdb/src/task/resize.js
Measurement protocol: https://github.com/2009seungbin-stack/my-first-repo/blob/f9d191aa5d7edc6c584c0b0cdb7b286bd51eacbf/tools/editorial/measure-resize-dimensions.py

Reproduce from a checkout containing the protocol, with the repository's requirements-test.txt and Playwright browsers installed:

    python tools/editorial/measure-resize-dimensions.py --base https://2b404dbc.nerulio.pages.dev --expected-sha c8ad20875e9504b29cc7890c98fd7b171afdcbdb --output test-results/resize-reproduction

For a new deployment, replace both --base and --expected-sha with its actual public URL and build.txt value. New measurements default to test-results and cannot overwrite existing published assets. The original preview can later be removed by the hosting provider; the exact downloaded bytes remain here.

For 128 x 96, the enabled limit yields 32 x 24 in all three modes; without it the output is 128 x 96. For 128 x 128, the enabled limit yields 24 x 24; without it the output is 128 x 128. Equal output dimensions do not mean identical crops: the capped contain result has a 24 x 18 opaque picture with 3 transparent rows above and below. Cover crops; stretch changes the picture's aspect ratio.

manifest.json covers all 27 evidence members other than itself. evidence.zip contains those members plus manifest.json, with no external paths or authentication data.
