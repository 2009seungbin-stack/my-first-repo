# Nerulio 제품 로드맵 — 경쟁 도구 상위호환 + 단순한 첫 화면

기준일 2026-09-21. 경쟁 도구를 실제로 열어 합성 테스트 파일로 사용해 본 결과(Playwright Chromium, 영어 UI)와 그에 따른 재설계 계획이다. "테스트 통과"는 제품 품질의 증거가 아니다. 각 도구는 아래 경쟁 도구와 **같은 파일로 나란히 비교**해서 합격시킨다.

## 2. 공통 설계 원칙 (모든 도구)

1. **한 페이지 = 한 가지 일.** 범용 편집기 틀에 끼워 넣지 않는다. 기존 편집기는 "고급 편집기"로 남긴다.
2. **첫 화면은 큰 드롭존 하나.** 파일을 놓으면 기본값으로 바로 처리하거나(압축·변환), 바로 정리 화면이 뜬다(PDF).
3. **주 버튼은 하나**, 항상 같은 자리(오른쪽 아래/패널 맨 아래).
4. **결과를 크게**: −93%, 150KB → 12KB, 전후 비교 슬라이더, 페이지 수.
5. **여러 파일이 기본**: 목록, 파일별 결과, 모두 받기(ZIP).
6. **단계적 공개**: 기본 3가지 선택 → "고급 설정" 접힘(코덱·품질·목표 용량·메타데이터…) → "고급 편집기에서 열기".
7. **다음 작업 연결**: 결과 아래 "이어서 하기"로 파일을 들고 다음 도구로 이동(기기 안에서만 전달).
8. 홈은 **도구 목록 + 검색 + 드롭존**. 파일을 놓으면 종류를 보고 도구를 제안.

## 3. 기능 격차 (경쟁 도구 기능 → 우리 상태)

**PDF (iLovePDF 33개 + Sejda)** — 있음: 합치기, 분할, 압축(JPEG 재압축만), JPG↔PDF, 회전, 페이지 정리(편집기 안), 주석(텍스트·펜·형광·사각형·이미지). 없음: 썸네일 격자 정리 UX, 페이지 번호, 워터마크, 자르기(Crop), 보호/잠금 해제, 서명, 양식 채우기, Whiteout, 링크, 도형, 기존 텍스트 편집, OCR, 가리기(Redact), 비교, 복구, PDF/A, 스캔→PDF, Office↔PDF, HTML→PDF, 번역·요약(AI).
브라우저만으로 어려운 것: Office↔PDF 고품질 변환(서버 엔진 필요) — 마지막 순위, 품질이 안 되면 제공하지 않는다.

**이미지** — 있음: 압축, 변환, 크기, 자르기, 회전, 배경 제거(경량 모델), 업스케일(실험). 없음: MozJPEG/OxiPNG/AVIF 전용 인코더, 팔레트 축소, 워터마크, 얼굴 흐림, 메타데이터 제거 옵션, 배경 교체·지우기/복원 브러시, 일괄 이름 규칙.

**게임 에셋** — 있음: 도트 변환, 스프라이트 분리, 프레임 정규화, 균일 격자 시트, 팔레트 교체, 아틀라스 여백, 노멀맵, 타일 분할, 비트맵 폰트, 파비콘. 없음: **MaxRects 패킹(회전·트림)**, 엔진별 내보내기(Unity/Godot/Phaser/Pixi/Spine JSON, CSS), **애니메이션 미리보기(FPS)**, GIF/APNG↔시트, Lospec 팔레트 불러오기, 도트 편집(그리기·레이어·어니언 스킨), 타일셋 도구(오토타일·심리스 검사), 9-slice, 아웃라인/그림자 일괄, 색상 수 제한 미리보기.

## 4. 진행 순서

| 단계 | 내용 | 합격 기준 |
| --- | --- | --- |
| 0 | 공통 틀: 새 홈, 작업 페이지 틀(드롭존·목록·결과·고급 설정·이어서 하기·언어 전환), 파일 전달 | 기존 회귀 + 새 브라우저 테스트, 모바일 390px |
| 1 | 이미지 압축·변환·크기 변경을 새 틀로 (Squoosh 깊이 + 여러 장) | 같은 사진에서 Squoosh MozJPEG q75 대비 용량/SSIM 비교표 |
| 2 | **PDF 정리/합치기/분할**: 썸네일 격자, 끌어서 순서 변경, 페이지 단위 회전·삭제·복제·삽입, 여러 파일 혼합 | iLovePDF organize의 모든 동작 + 제한 없음 |
| 3 | **PDF 편집기 재작성**: Sejda 도구막대 수준(텍스트·이미지·서명·Whiteout·도형·링크·양식·주석), 페이지 번호·워터마크·자르기·보호/해제 | 기능 체크리스트 100%, 출력 PDF를 Acrobat/Chrome/pdf.js에서 검증 |
| 4 | **게임 에셋 스튜디오**: MaxRects 패커 + 엔진 내보내기, 애니메이션 미리보기, GIF↔시트, 팔레트(Lospec), 도트 편집 기본 | TexturePacker 무료판 기능 대비 체크리스트, 엔진에 실제 임포트 |

각 단계는 브랜치 → 미리보기 URL → 확인 → 병합. 이전 화면은 단계별로 교체하며, 교체 전까지 기존 경로는 그대로 동작한다.
