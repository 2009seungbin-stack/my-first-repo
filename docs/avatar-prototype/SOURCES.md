# Pixel Avatar visual gate provenance

2026-09-28. The four 16×16 character combinations and every part shape in `render_lineup.py` were drawn from scratch for Nerulio with Pillow primitive pixel coordinates. No competitor, Picrew, stock sprite, or user image is used. The author dedicates the original art and generated PNGs to the public domain under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/), to the extent of the author's rights. The script itself remains project source under the repository license.

This is a visual feasibility study, not the product asset catalog. It has two face shapes (stepped round / angular), two hairstyles (bob / swept), two eye sets (bright / sleepy), and two outfits (hoodie / jacket). Columns 1–2 hold hair/eyes/outfit constant to expose only the jaw/cheek difference. Columns 3–4 hold face/hair/outfit constant to expose only the eye difference. Each source pixel is a member of an explicit four-shade skin, hair, outfit, or eye ramp, plus transparency. RGB values and all coordinates are in the script. The 32/48/64px outputs use exact nearest-neighbor scale factors 2/3/4; the script asserts every output pixel matches its logical source, belongs to the declared palette, and retains a transparent corner after reopening the PNG. No smoothing, resampling between target sizes, or global hue shift occurs.

`output/lineup-32-48-64.png` is the review sheet; `output/avatar-*-16.png`, `*-32.png`, `*-48.png`, and `*-64.png` are independently inspectable transparent PNGs. The sheet is only a presentation composition and is not a proposed export format.
