## Turn a release announcement into a question about your code

llama.cpp released 1.0.0 on November 13, 2026, announcing removal of older public APIs. For an app or game plugin that calls the C API directly, one useful question before upgrading is precise: **does the new header still declare the names my code uses?**

Starting with the official release linked from Nerulio's collected news, we checked the same small C++ sources against 0.9.0 and 1.0.0. Six legacy patterns, four replacement names and one current-API control made eleven probes per version, or 22 compiler invocations.

An AI agent ran the actual compiler and prepared this report. No separate human review or model-running experience is claimed. This checks declarations; it does not link a DLL, validate an ABI, load a model or measure inference speed.

## Fixed inputs and environment

We pinned source commits rather than recording tag names alone.

- 0.9.0: `cd959bae99ff4bed22bef2604f45241c09bbb8c8`
- 1.0.0: `b1b770d90d94cad9e9ea5b993bdbc383a522fb28`

Each version supplied `llama.h` and six ggml headers required to read it: fourteen official headers in total. Their sizes and Git blob hashes were checked before compilation. The [measurement JSON](/assets/editorial/2026-11-14-llama-api/measurements.json) records each URL, commit and SHA-256.

The environment was Windows NT build 26200, Python 3.10.11 and Microsoft C/C++ 19.51.36256.0 x64 in C++17 mode, with Visual C++ include folder 14.51.36231 and Windows SDK headers 10.0.26100.0. `/Zs` checks syntax only. Deprecation warnings were retained rather than promoted to errors, so ‘pass’ below does not mean warning-free.

The function probes take a name's address. For example, the [legacy load probe](/assets/editorial/2026-11-14-llama-api/legacy-model-load.cpp) references `llama_load_model_from_file`. It passed with a deprecation warning on 0.9.0, then failed with C2065, an undeclared identifier, on 1.0.0. Inspect the [actual diagnostic](/assets/editorial/2026-11-14-llama-api/v1.0.0-legacy-model-load.txt).

All five legacy function probes failed with C2065. The [field probe](/assets/editorial/2026-11-14-llama-api/legacy-defrag-field.cpp), assigning `llama_context_params::defrag_thold`, failed on 1.0.0 with C2039, a missing member. The control references current `llama_model_default_params` and `llama_batch_init` declarations and passed on both. That provides evidence against a missing include path or standard library causing every probe to fail.

## What to check in a project

These four tested pairs already had the replacement names declared in 0.9.0:

- `llama_load_model_from_file` → `llama_model_load_from_file`
- `llama_new_context_with_model` → `llama_init_from_model`
- `llama_free_model` → `llama_model_free`
- `llama_n_vocab` → `llama_vocab_n_tokens`

Search your project and native dependencies for the old names, then read the 0.9.0 deprecation hints alongside the new declarations. Address-taking does not validate every argument, return value or lifetime rule. After changing call sites, rebuild the actual project and exercise its loading and release paths.

`llama_set_warmup` needs a separate review: the older header advises user code to perform warmup runs manually. This experiment supplies no arbitrary replacement function for it. Code assigning `defrag_thold` also needs review against the new structure. Compatibility of an HTTP client that does not call this C API cannot be determined from these declaration probes.

## Reproduce and keep the scope clear

The [evidence ZIP](/assets/editorial/2026-11-14-llama-api/evidence.zip) contains eleven original C++ probe files, 22 diagnostic logs, measurements, explanation, the script and input pins. The [manifest](/assets/editorial/2026-11-14-llama-api/manifest.json) lists the sizes and SHA-256 hashes of 37 files, excluding the manifest and ZIP themselves. The archive contains those files plus the manifest: 38 members.

From a configured x64 Visual Studio developer shell, open the extracted folder and run:

```
python measure-llama-api.py --compiler cl --output ./new-evidence
```

Use a new or empty output directory. The script fetches and verifies official headers at fixed commits. The ZIP does not redistribute the compiler, SDK or upstream headers. The original probes and script are offered under CC0-1.0. The [README](/assets/editorial/2026-11-14-llama-api/README.md) explains setup and scope.

This dataset establishes eleven declaration results for one Windows compiler and two pinned header versions. Replacing a DLL in an old binary, using a particular GPU or model, and comparing speed require separate execution tests. Combine this small check with your project's own build and model-running results when deciding whether to upgrade.
