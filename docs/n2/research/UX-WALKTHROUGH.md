# Nerulio 2.0 UX 워크스루 (페르소나 4명)

- 일시: 2026-09-28 (로컬 `node tools/platform/dev-server.mjs 8797`, 시드 데이터 + SAMPLE 게시글)
- 방법: Python Playwright(Chromium), 1280px·390px 두 폭, `/__dev/login`으로 로그인. 스크린샷은 `/tmp/ux-shots/`에 있습니다(저장소 밖).
- 심각도: **blocker**(과업을 끝낼 수 없음) / **major**(틀린 답을 얻거나, 크게 헤매거나, 데이터가 오염됨) / **minor**(어색함·다듬기)
- 참고: dev 서버는 `/src`, `/assets`와 플랫폼 경로만 서빙합니다. 그래서 `/ko/account/`, `/ko/`(도구), `/ko/about/`, `/ko/terms/`, `/api/v1/auth/google/start`는 로컬에서 모두 404가 납니다. 이 경로들은 아래 목록에서 뺐고, 운영 환경에서 따로 확인해야 합니다.

## 페르소나 1 — AI 사용자 (30대 직장인)

### 지나간 경로
1. `/ko/community/` 첫 화면. 상태나 요금을 바로 보여 주는 블록이 없어서 헤더 검색창에 `Claude 장애`를 입력했습니다.
2. `/ko/search/?q=Claude+장애` → 결과 0건. `장애`, `상태`, `가격`도 모두 0건이었습니다.
3. 검색어를 `Claude`로 줄이자 채널 20개가 나왔고, `Claude` 채널을 눌렀습니다 → `/ko/ai/claude/`.
4. 서비스 상태 박스는 전부 "확인 전"이었습니다. 작은 링크 "사용자 리포트 보기 ›"를 따라가 `/ko/ai/claude/status`에 들어가서야 **"사용자 리포트 급증"**을 볼 수 있었습니다.
5. 요금: Claude 채널 위키에서 Pro $20을 찾았습니다. `ChatGPT Plus`를 검색해 `/ko/ai/chatgpt-plus/`에서 ₩29,000을 찾았습니다. 두 요금제를 비교하는 표 `/ko/ai/?type=plan`은 AI 허브 탭 "요금제 19"를 눌러야만 나옵니다(채널에서는 링크가 없습니다).
6. API 최저가: Claude 채널의 "지금 쓸 수 있는 모델" 표에서는 Sonnet 5($2/$10)가 가장 싸 보였습니다. 실제 최저가인 Haiku 4.5($1/$5)는 `/ko/ai/?type=model`의 62행 표 중간에 있었습니다.

### 잘 된 점
- 상태 페이지는 공식 기록과 사용자 리포트를 나눠 보여 주고, 차트·버튼·안내문 구성이 명확합니다. 로그인한 뒤 리포트를 누르면 토스트가 뜨고, 분당 3회 제한 메시지("너무 빨라요. 1분 뒤에 다시 해 주세요.")도 자연스럽습니다.
- 요금제 비교(`?type=plan`)와 모델 API 가격 비교(`?type=model`) 표 자체는 훌륭합니다. 출처("공식")와 확인일이 붙어 있어 신뢰가 갑니다.
- 채널 상단의 "방금 바뀐 것" 박스와 NEW 뱃지로 Opus 5.5 출시가 한눈에 보입니다.

## 페르소나 2 — 한글패치 쓰는 PC 게이머

### 지나간 경로
1. 검색 `테라리아` → 한글패치 채널만 나오고 게임 채널 `Terraria`는 나오지 않았습니다. `Terraria`로 다시 검색해서 찾았습니다.
2. 검색 `케이브 오브 쿼드` → 0건. `qud` → 한글패치 채널 2개가 게임 채널보다 먼저 나왔습니다.
3. `/ko/games/caves-of-qud/`에서 "현재 버전 1.04"와 "한글패치 (qudkorean) v1.0.2 1.04 호환 **알 수 없음**"을 확인했습니다.
4. 로그인한 뒤 "✓ 작동"을 누르자 확인 창 없이 곧바로 공개 글 `/ko/games/caves-of-qud/6`("Caves of Qud 한글패치 (qudkorean) × Caves of Qud 1.04: 작동", 본문 "작동")이 만들어졌습니다.
5. 다시 누르니 똑같은 글 `/7`이 또 만들어졌습니다. 내가 쓴 글은 채널 목록에서 눈으로 찾아야 했습니다. `/ko/community/me`에는 "내 글"이 없습니다.
6. 자세한 호환 리포트 양식(OS·기기·패치 버전)은 `/ko/games/caves-of-qud/write`에서 말머리를 "리포트"로 바꿔야만 나옵니다.

### 잘 된 점
- 게임 채널 상단 "최신 업데이트 + 한글패치 호환 + 작동/일부/안 됨" 스트립은 이 사이트의 핵심 가치를 가장 잘 보여 줍니다.
- 게임 허브 `/ko/games/`의 "업데이트로 한글패치 확인이 필요한 게임"(Terraria 1.4.5.7, 패치는 1.4.5.3에서 작동)이 정확히 필요한 정보입니다.
- 패치 채널의 "Nerulio는 패치 파일을 올리거나 보관하지 않습니다" 문구와 "제작자 배포처로 이동 ↗"이 명확합니다.
- 구조화 리포트 양식(`write?kind=report`)은 게임 버전을 미리 채워 주고, "3명 이상이면 커뮤니티 검증"이라는 안내도 좋습니다.

## 우선 고칠 10가지

1. **모더레이터 임시조치 후 복구 불가 (blocker).** 숨긴 글이 모더레이터에게도 404가 되고, 큐에서도 사라집니다. "임시조치 중" 탭, 모더레이터 전용 숨김 글 보기, 복구 버튼, 한국어 오류 메시지를 추가합니다.
2. **원클릭 "✓ 작동"이 중복 공개 글을 만들고 숫자가 부풀려짐.** 원클릭은 사용자·조합당 1표(수정 가능)로 바꾸고 글은 만들지 않습니다. "자세히 리포트 ›"로 구조화 양식을 엽니다. 스트립·호환표·글의 숫자를 "확인한 사람 수"로 통일합니다.
3. **검색 개선.** 여러 단어는 AND로 매칭하고, 한글 별칭(테라리아 등)을 추가하고, 채널을 우선 정렬합니다. "장애/요금/API 가격" 같은 의도어는 상태·요금 비교·모델 가격표로 바로 보냅니다.
4. **채널 상태 박스와 상태 페이지 신호 일치.** 채널의 "확인 전"과 상태 페이지의 "리포트 급증"이 어긋납니다. 사용자 리포트 신호를 채널 박스에도 보여 줍니다.
5. **"지금 쓸 수 있는 모델" 표가 최저가 모델(Haiku 4.5)을 빠뜨림.** 모든 활성 모델, 최저가·최신 배지, "전체 가격 비교 ›" 링크를 넣고, 비교표에는 회사 필터와 정렬을 추가합니다.
6. **요금 비교에서 통화 혼재와 영어 메모.** 달러 요금 옆에 원화 환산을 두고, 부가세 포함 여부를 표시하고, "요금 참고"를 한국어로 옮깁니다.
7. **내 레이더 가독성.** 채널명 반복을 없애고, 이벤트 날짜(D-day)를 기준으로 쓰고, 날짜 형식을 통일합니다. 모바일에서 내용이 보이게 줄바꿈합니다. "내 구독만" 토글과 굿즈 마감 섹션도 추가합니다.
8. **로그인 상태가 반영되지 않는 화면.** 첫 화면의 로그인 박스를 내 구독 박스로 바꾸고, 모바일 헤더에 레이더·알림 진입점을 넣고, 댓글 placeholder를 고칩니다.
9. **신고·모더레이터 문구와 정보.** "리포트를 남겼어요"를 "신고가 접수됐어요"로 바꾸고 원래 글로 돌려보냅니다. 신고 화면에 대상 글을 보여 주고, 사유 기본값을 없애고, 큐에 한국어 사유·신고 설명·본문 미리보기를 표시합니다.
10. **벤치 글과 벤치 보드 연결, 마크다운 표 지원.** 말머리 "벤치"에 구조화 필드를 붙여 보드에 집계하고, GFM 표와 URL 자동 링크를 렌더링합니다. 5070 ↔ 4070 나란히 비교 화면도 만듭니다.
