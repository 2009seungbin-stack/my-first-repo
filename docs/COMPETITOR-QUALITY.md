# Quality comparison scope — 2026-09-21

No competitor service was scraped and no user files were uploaded. Public documentation establishes available features, not measured parity. The measurements below use our local fixtures and openly available implementations. No claim of being best or reaching Flagship follows from them.

| Area | Public reference | Implemented here | Measured comparison and remaining gap |
|---|---|---|---|
| Upscale | [Upscayl](https://github.com/upscayl/upscayl) provides a native GPU-oriented AI workflow | Experimental pinned Swin2SR, tiled 2×/4×, classical fallback | NASA portrait: 2× 34.61 dB / SSIM .97717 vs Pica Lanczos 31.04 / .95846; 4× 28.63 / .92623 vs 25.92 / .86374. Only one photo; WASM is slow. Not a comparison against Upscayl outputs. 8K ML, anime and broad alpha/edge acceptance remain unverified. |
| Background | [rembg](https://github.com/danielgatis/rembg) offers several segmentation models and local processing | General BiRefNet lite and full-resolution guided matte refinement; separate color removal | Actual portrait PNG inspected; simple alpha landmarks pass. No ground-truth hair/fur/transparent-object IoU suite yet. It remains experimental, not a Flagship remover. |
| Compression | [Squoosh](https://github.com/GoogleChromeLabs/squoosh) provides local browser compression with multiple codec implementations | Actual native codec probes, alpha-aware candidate search, target size and sampled SSIM | Full-resolution decoded checks on photo, text UI, illustration, transparent logo, noise and already-compressed JPEG. Browser encoders do not replace MozJPEG/AVIF WASM or a perceptual human evaluation. Squoosh parity has not been measured. |
| Pixel/game | [LibreSprite](https://github.com/LibreSprite/LibreSprite) offers a full sprite drawing/animation workflow | Oklab palette extraction, locked palette reuse, FS/Bayer/no-dither, native sizes and alignment | Deterministic alpha/palette/geometry checks and decoded game-pack integration. Automated conversion is not manual pixel-art authorship; silhouette and character quality need authored goldens. |
| PDF | [qpdf](https://qpdf.readthedocs.io/en/stable/cli.html) supports structural rewriting, object streams and cleanup | Native copy/annotations, selective RGB JPEG recompression, separate raster mode | 320-page mixed fixture retains searchable text, rotation/crop and native vector marks. General PDF optimization, encrypted input, signed/form fidelity and arbitrary embedded image formats remain behind mature PDF tooling. |
| Video | [FFmpeg](https://ffmpeg.org/ffmpeg.html) supports stream copy, filtering and broad codec transcoding | Ranged Blob demux, keyframe remux, WebCodecs encode, MP4/WebM and OPFS | Actual 629,052,062-byte / 3,600-second input, 60-second end-section remux; short precise encoding checked by FFprobe. Native codec breadth, HDR, multiple tracks and difficult VFR files remain gaps. No FFmpeg quality/speed superiority claim. |

The faster compact Real-ESRGAN candidate was **rejected as the default**: on the same portrait it scored 27.28/.92921 at 2× and 23.13/.83323 at 4×, below classical Lanczos despite lower latency. Runtime speed alone is not acceptance.

Fixture limitations are deliberate report fields. Synthetic signals make duration, alpha, coordinates and palette counts reproducible; they cannot establish hair quality, photographic realism or human preference.
