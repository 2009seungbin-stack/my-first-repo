# 검증 기록 · 2026-09-20

## 실행한 검사

- `npm run check`: 주요 JavaScript 모듈 문법 검사 성공.
- `npm test`: 56개 통과. 크기/범위 검증, 딥링크, 팔레트 색 수/투명도/디더링, 경계 연결 배경제거, 외곽선, 페이지 회전 좌표, CRC32, ZIP, GIF, 23개 정적 별칭 경로.
- `npm run build`: 홈 포함 24개 정적 진입 HTML 생성.
- `python tests/browser.py --in-memory`: 38개 통과. Chromium의 실제 DOM/Canvas 편집과 파일 다운로드, JPEG/PNG 시그니처와 목표 용량, 실제 48×48 에셋, 네 크기 ZIP CRC/해상도, 단색 배경제거 알파, 편집기 사이 원본 재사용, 390px 레이아웃, 딥링크 초기값, 실제 WebM 입력/프레임/GIF/구간 출력/재열기.
- GIF는 Pillow로 프레임 개수와 크기를 확인했습니다. ZIP도 Python zipfile로 독립적으로 읽었습니다.

## 환경 한계

이 실행 환경은 로컬 HTTP 브라우저 탐색을 차단했습니다. `--in-memory`는 동일한 소스를 Blob 모듈로 마운트하고 주소/history 접근만 시험용으로 바꿉니다. HTTP 탐색·서버 헤더·배포 CSP·검색엔진 동작은 검증하지 않습니다.

Worker 시작이 차단되어 픽셀/단색 제거/GIF는 제품 코드의 CPU 호환 경로로 실행됐습니다. 실제 Worker 성공 경로와 메모리 사용량·CPU 점유·배터리·실물 저사양 성능은 미검증입니다.

외부 다운로드를 쓰는 PDF.js/pdf-lib, HEIC, MP3, MODNet 통합은 이 환경에서 실행 성공을 검증하지 못했습니다. 인터페이스만 구현했고 실제 사용자 브라우저에서 대표 파일로 추가 검사해야 합니다. AI 복원 업스케일은 구현하지 않았습니다.

## 다시 검사하기

Node.js 20 이상에서 `npm test`, `npm run check`, `npm run build`를 실행합니다. 브라우저 검사는 Python Playwright, Pillow, `/usr/bin/chromium`이 필요합니다. 테스트 경로는 실행 환경에 맞게 변경할 수 있습니다. FFmpeg가 있으면 2초짜리 시험 영상을 만들어 미디어 검사 5개를 더 수행합니다.

일반 환경에서는 서버 실행 후 `python tests/browser.py`로 HTTP 경로를 검사합니다. 제한 환경 전용 `--in-memory` 결과를 공개 배포 E2E 성공으로 해석하면 안 됩니다.
